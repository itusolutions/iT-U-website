# iTu Solutions image assets

All artwork in this folder is original, locally stored SVG illustration artwork. It scales cleanly on mobile and desktop and does not depend on third-party image hosts.

- `logo.svg`, `favicon.svg`: brand mark and browser icon
- `hero-tech.svg`: homepage/general technology hero
- Service illustrations: computer repairs, website development, software installation, operating-system updates, IT support, networking, cybersecurity, data backup and hardware upgrades.
